# Markdown转Word/PDF 验证计划

## 验证目标
验证所有Markdown元素在Word和PDF输出中的格式是否符合需求文档要求，特别关注流程图的规范性。

## 验证顺序
1. **Word格式验证**（优先）
2. **PDF格式验证**（后续）

## Word格式验证清单

### 1. 基础文本格式
- [ ] **标题样式**
  - H1~H6是否正确映射到Word Heading1~Heading6
  - 标题字体、字号是否符合要求
  - 标题编号是否正常（如启用）

- [ ] **段落格式**
  - 段落间距是否保留
  - 换行和空行是否正确处理
  - 首行缩进是否正常

- [ ] **强调格式**
  - `*italic*` 是否转为斜体
  - `**bold**` 是否转为粗体

### 2. 列表格式
- [ ] **无序列表**
  - 符号是否正确（- 或 *）
  - 嵌套层级是否正确缩进

- [ ] **有序列表**
  - 编号是否正确（1. 2. 3.）
  - 嵌套层级是否正确

### 3. 表格格式
- [ ] **基本表格**
  - 表头是否正确显示
  - 列宽是否自动调整
  - 边框样式是否正常

- [ ] **复杂表格**
  - 对齐方式是否正确
  - 合并单元格是否支持

### 4. 代码块
- [ ] **语法高亮**
  - 代码块背景色是否显示
  - 等宽字体是否正确应用（Courier New）
  - 语言标识是否正确

- [ ] **内联代码**
  - `code` 格式是否正确显示

### 5. 引用块
- [ ] **Blockquote**
  - 引用样式是否正确（左侧边距、灰色背景等）
  - 嵌套引用是否支持

### 6. 图片
- [ ] **本地图片**
  - 图片是否正确插入
  - 宽高比例是否保持
  - 缩放是否正常

- [ ] **远程图片**
  - URL图片是否下载并插入（当前未实现）

### 7. 链接
- [ ] **超链接**
  - `[text](url)` 是否转为可点击链接
  - 链接颜色和样式是否正常

### 8. 分割线
- [ ] **水平线**
  - `---` 或 `***` 是否转为分隔线
  - 样式是否符合要求

### 9. 流程图（重点验证）
- [ ] **Mermaid流程图**
  - 是否正确检测mermaid代码块
  - 渲染是否成功（需mmdc）
  - **线的走向**：必须是直线，不能弯曲
  - **判断框出线**：
    - 入口：上方顶点
    - 成立出口：正下方顶点
    - 不成立出口：右中方顶点
  - **符号形状**：
    - 数据符号：平行四边形
    - 处理符号：矩形
    - 判断：菱形
    - 循环界限：去角矩形
  - **字体**：楷体，10号
  - **流向**：从左到右，从上到下
  - **箭头**：流线必须有箭头
  - **布局**：避免流线交叉，并行流程同高

- [ ] **PlantUML流程图**
  - 是否正确检测plantuml代码块
  - 渲染是否成功（需plantuml）

- [ ] **降级处理**
  - 渲染失败时是否降级为代码块显示

## PDF格式验证清单

### 1. 基础格式（同Word）
- [ ] 标题、段落、列表、表格、代码块、引用、图片、链接、分割线

### 2. PDF特有格式
- [ ] **页面设置**
  - A4页面是否正确
  - 页边距是否符合要求（2.5cm）

- [ ] **页眉页脚**
  - 是否支持（当前未实现）

- [ ] **页码**
  - 是否正确显示

- [ ] **字体嵌入**
  - 中文字体是否正确嵌入
  - 特殊字符是否正常显示

### 3. 流程图（同Word）
- [ ] 流程图在PDF中的显示效果
- [ ] 是否保持与Word一致的规范

## 验证方法

### 1. 测试用例验证
```bash
# 运行完整测试套件
pytest tests/ -v

# 运行流程图测试
pytest tests/test_flowchart.py -v
```

### 2. 实际文件验证
创建测试Markdown文件，包含所有格式元素，执行转换后人工审核。

### 3. 流程图专项验证
```bash
# 检查mmdc是否可用
mmdc --version

# 测试单个流程图渲染
mmdc -i test.mmd -o test.png -t default
```

## 验证工具

1. **Word验证**：Microsoft Word或WPS Office
2. **PDF验证**：Adobe Acrobat或浏览器预览
3. **流程图验证**：图片查看器 + 人工比对G-C110规范

## 预期问题

1. **流程图线弯曲**
   - 原因：Mermaid默认使用曲线连接
   - 解决方案：需要自定义Mermaid主题或配置

2. **判断框出线不规范**
   - 原因：Mermaid默认布局算法
   - 解决方案：需要调整节点位置或使用自定义CSS

3. **字体不符合要求**
   - 原因：默认字体非楷体
   - 解决方案：需要在Mermaid主题中配置字体

## 验证优先级

1. **高优先级**
   - 流程图线的走向（直线 vs 曲线）
   - 判断框出线规范
   - 基本文本格式

2. **中优先级**
   - 表格、列表、代码块
   - 图片插入

3. **低优先级**
   - 页眉页脚
   - 模板支持
