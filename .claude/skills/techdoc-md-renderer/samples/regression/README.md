# Regression Samples

This directory contains small Markdown documents used to validate product-level conversion behavior.

- `standard_tables.md`: standard document tables, split-table normalization and list bullets.
- `register_table.md`: register and bitfield table strategies.
- `interface_spec.md`: interface fields, BNF and long token wrapping.
- `mixed_cell_content.md`: HTML table cells with lists, code, line breaks and inline images.
