# 标准文件表格样例

## 范围

本文用于回归标准文件中的普通表格、拆分表格合并和短章节排版。

## 术语和定义

| 术语 | 定义 |
| ---- | ---- |
| ECU | 电子控制单元 |
| PDU | 电源分配单元 |

## 产品代号

| 产品名称 | 产品域 | 代号 |
| -------- | ------ | ---- |
| BOBC+DCDC项目 | PDU | 32 |

| 底盘域 | CMC | 36 |
| :----- | :-- | :- |
| 车身域 | BCM | 40 |

## 要求

- 接口名称应清晰表达用途；
- 同一类接口应保持一致的命名结构；
- 缩略语应在术语表中定义。
